# TransistorTester-Hamtronik
 TransistorTester edit by Hamtronik
project original dari https://www.mikrocontroller.net/articles/AVR_Transistortester
 Project di repo ini menggunakan chip Atmega328, fusbit clock internal tanpa kristal.
 Pengaturan Fusbit:
 Lfuse:0xe2 Hfuse:0xd9 Efuse:0x04 atau 0xfc
